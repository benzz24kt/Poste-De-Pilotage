    Revue hebdomadaire

    ~20-30 minutes, toujours le même jour. Elle remet le compteur à zéro pour la semaine suivante.

    • Vérifier les cases cochées sur les deux feuilles de route — corriger si besoin.

    • Ajuster le planning de la semaine si un jour type n'a pas fonctionné.

    Memecoin — les fondamentaux

    Comment ça marche, et comment opérer

    Memecoin — spécial débutant

    Comprendre le vocabulaire avant de trader

    Les memecoins sont parmi les actifs les plus rapides et les plus risqués du marché crypto. Lis ce lexique et utilise les outils de vérification ci-dessous avant de mettre le moindre dollar dans un token.

    Lancement et actions du créateur (le « Dev »)

    Dev

    Le développeur : la personne, souvent anonyme, qui a créé et lancé le token.

    Dev buy / Dev sold

    Le dev achète (buy) ou revend (sold) une partie des tokens qu'il a créés. Un gros « dev sold » juste après le lancement est un signal d'alarme classique.

    DEX paid / Dev paid

    Le dev a payé pour que les infos du token (logo, réseaux sociaux) soient mises en avant sur un site comme DexScreener. Ça améliore la visibilité, pas la fiabilité du projet.

    Bundle / Bundled

    Plusieurs wallets liés au dev achètent le token dans la même transaction au lancement, pour gonfler artificiellement le prix ou l'illusion de demande.

    Sécurité et liquidité

    Rug pull / Rug

    Le dev retire soudainement toute la liquidité (ou vend tout), le prix s'effondre à quasi zéro. Le risque n°1 sur les memecoins.

    Burn LP / Lock LP

    La liquidité est détruite (burn) ou verrouillée pour une durée fixe (lock), ce qui rend un rug pull plus difficile. Bon signe, jamais une garantie totale.

    Honeypot

    Un piège : tu peux acheter le token, mais le contrat t'empêche techniquement de le revendre. À vérifier avant d'acheter, jamais après.

    Mcap (Market Cap)

    Valeur totale du token = prix × nombre de tokens en circulation. Sur les memecoins, on raisonne presque toujours en mcap ($10k, $100k, $1M…) plutôt qu'en prix unitaire.

    Dynamique de marché

    Boost

    Un dev ou un trader paie pour mettre en avant le token dans les classements d'une plateforme. Augmente la visibilité, ne dit rien sur la qualité.

    Pump / Dump

    Le prix monte très vite (pump), puis chute tout aussi vite (dump) quand les premiers acheteurs prennent leurs gains.

    Bonding curve

    La courbe qui fixe le prix en fonction de la quantité déjà achetée, utilisée par les plateformes de lancement (type pump.fun) avant qu'un token soit listé sur un vrai DEX.

    CTO (Community Takeover)

    Le dev original abandonne le projet ; la communauté reprend le contrôle (réseaux, parfois le contrat) pour tenter de le faire vivre sans lui.

    Comportements des traders

    Jeet

    Un trader qui revend très vite, souvent dès le moindre profit, par peur de le perdre.

    Diamond hands

    Un trader qui garde sa position malgré la volatilité, sans paniquer au moindre mouvement.

    Snipers

    Des bots ou traders ultra-rapides qui achètent dans les toutes premières secondes du lancement, avant la plupart des humains.

    Shill

    Faire la promotion agressive d'un token pour inciter d'autres personnes à l'acheter — généralement dans l'intérêt de celui qui shill.
